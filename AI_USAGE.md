# AI Tools Usage

AI tools (Claude by Anthropic and GitHub Copilot) are used as support, not as a substitute for understanding. All core project elements—research question, methodology, data choices, portfolio design and result interpretation—are defined and carried out by me. AI contributes mainly to code debugging/optimization, syntax and style suggestions, and documentation polishing. Overall, I am responsible for the conceptual design, algorithmic logic, 100% of the analytical conclusions, and I can fully explain and modify any part of the codebase.
